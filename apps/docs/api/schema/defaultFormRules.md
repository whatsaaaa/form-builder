# defaultFormRules

The built-in form rules, by name: `sameAs`, `differentFrom` and `compare`.

```ts
const formRules = defaultFormRules
```

## Explanation

Every builder has them, unless `includeDefaultRules` is `false`. Add them back then with `formRules: defaultFormRules`.
