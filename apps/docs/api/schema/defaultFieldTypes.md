# defaultFieldTypes

The built-in field types, by name: `text`, `textarea`, `email`, `password`, `url`, `tel`, `number`, `checkbox`, `date`, `time`, `datetime`, `select`, `radio`, `multiselect`, `file`, `heading`, `paragraph`, `divider`, `group` and `array`.

```ts
const fieldTypes = defaultFieldTypes
```

## Explanation

Every builder has them. Your own types merge over them by name. The [built-in field types](/api/schema/field-types) reference lists each one with its kind and props.
