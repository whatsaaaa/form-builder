# JsonRule

One rule on a field.

## Definition

- `JsonRule`
  - `rule` <code>string</code>: a registered rule
  - `message` <code>string</code>: optional, Valibot's own message without it
  - `[param: string]` <code>unknown</code>: the rule's params, like `value`
